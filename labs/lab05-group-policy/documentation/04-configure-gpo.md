# Configure Group Policy

## Objective

Configure the **IT Desktop Policy** Group Policy Object to prevent users from accessing the Control Panel.

## Steps

1. Edit the **IT Desktop Policy** GPO.
2. Navigate to:

   User Configuration → Policies → Administrative Templates → Control Panel

3. Open **Prohibit access to Control Panel and PC settings**.
4. Set the policy to **Enabled**.

## Result

Users affected by this Group Policy can no longer open the Control Panel or Windows Settings.
