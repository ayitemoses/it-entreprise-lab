# Review Multi-Factor Authentication (MFA)

## Objective

Review the Multi-Factor Authentication (MFA) capabilities available in the Microsoft Entra ID environment.

## Steps

1. Sign in to the Microsoft Entra admin center.
2. Navigate to **Protection > Authentication methods**.
3. Review the available authentication methods and policies.
4. Identify the authentication options supported by the current Microsoft 365 subscription.

## Verification

* Authentication methods were successfully reviewed.
* The available MFA configuration options were identified.
* The current Microsoft 365 Business Basic subscription was confirmed to have limited Microsoft Entra ID features.

## Notes

The Microsoft 365 Business Basic subscription includes Microsoft Entra ID Free. Advanced identity protection features such as Conditional Access, Identity Protection, and Privileged Identity Management require Microsoft Entra ID P1 or P2 licenses.

## Result

The available authentication methods were reviewed, and the licensing limitations for advanced Microsoft Entra ID security features were documented.
