# Configure DHCP Scope Options

## Objective

Configure the DHCP scope with the required network options.

## Steps

1. Configure the default gateway:
   - 192.168.10.1
2. Configure the DNS server:
   - 192.168.10.10
3. Configure the DNS domain name:
   - techsolutions.local
4. Activate the DHCP scope.

## Result

DHCP clients automatically receive the gateway, DNS server, and DNS domain name when obtaining an IP address.
