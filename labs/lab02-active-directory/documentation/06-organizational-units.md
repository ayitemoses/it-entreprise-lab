# Active Directory Organizational Units

## Objective

Create an organizational structure to manage users, computers and groups inside the TechSolutions Active Directory domain.

## OU Structure

techsolutions.local

├── Users
│ ├── IT
│ ├── HR
│ ├── Finance
│ └── Sales
│
├── Computers
│ ├── Workstations
│ └── Servers
│
└── Groups


## Purpose

### Users OU

Contains user accounts organized by department.

### Computers OU

Contains computer accounts separated between workstations and servers.

### Groups OU

Contains security groups used to manage permissions and access.

## Status

Organizational structure created successfully.
