# Create an IPv4 Scope

## Objective

Create an IPv4 DHCP scope for the TechSolutions network.

## Steps

1. Open the DHCP console.
2. Right-click **IPv4** and select **New Scope**.
3. Configure the scope:
   - Name: **TechSolutions LAN**
   - Start IP: **192.168.10.100**
   - End IP: **192.168.10.200**
   - Subnet Mask: **255.255.255.0**
4. Keep the default lease duration.
5. Choose to configure DHCP options later.

## Result

An IPv4 scope is created and ready to be configured with network options.
