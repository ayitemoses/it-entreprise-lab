## Status

⏳ In Progress

## Objective

Learn how to create, configure, and apply Group Policy Objects (GPO) in an Active Directory environment.

## Environment

- Windows Server 2025
- Domain Controller: DC01
- Windows 11 Client: WIN11-01
- Domain: techsolutions.local

## Skills Practiced

- Create and link GPOs
- Apply user and computer policies
- Force Group Policy updates
- Validate applied policies
- Troubleshoot GPOs
