# Active Directory Security Groups

## Objective

Create security groups to manage user access and permissions in the TechSolutions Active Directory environment.

## Naming Convention

The following convention is used:

- GG = Global Group
- Department = Organizational area
- Security group = Used for access management

## Created Groups

| Group Name | Purpose |
|---|---|
| GG-IT-Admins | IT administrators |
| GG-HR-Users | Human Resources users |
| GG-Finance-Users | Finance department users |
| GG-Sales-Users | Sales department users |

## Configuration

All groups were created with:

- Group Scope: Global
- Group Type: Security

## Validation

Security groups were successfully created in:
