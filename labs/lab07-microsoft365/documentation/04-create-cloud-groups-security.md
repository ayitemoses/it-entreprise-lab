# Create Microsoft 365 Security Groups

## Objective

Create Microsoft 365 security groups to organize users by department and simplify access management.

## Steps

1. Sign in to the Microsoft 365 Admin Center.
2. Navigate to **Teams & groups > Active teams & groups**.
3. Select **Add a group**.
4. Choose **Security** as the group type.
5. Create the following groups:

   * IT
   * Human Resources
   * Sales
   * Finance
6. Add the appropriate users to each department group.
7. Save the configuration.

## Verification

* All four security groups have been created.
* Each user is assigned to the correct department group.
* The groups appear in the Active groups list.

## Result

Microsoft 365 security groups have been successfully created and populated with the appropriate users. These groups are ready for use with Microsoft Entra ID, Intune, and future access management configurations.
