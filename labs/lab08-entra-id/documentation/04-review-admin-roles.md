# Microsoft Entra Administrator Roles

## Objective

Review and configure administrative roles in Microsoft Entra ID using Role-Based Access Control (RBAC).

## Steps

1. Open the Microsoft Entra admin center.
2. Navigate to:

   * Identity
   * Roles & admins
3. Review available administrative roles.
4. Verify the Global Administrator assignment.
5. Assign a limited administrative role to a test user if required.

## Verification

* Global Administrator role is confirmed.
* Administrative roles are available.
* Role assignments follow the principle of least privilege.

## Result

Microsoft Entra ID administrative roles have been reviewed and configured to support delegated identity management.
