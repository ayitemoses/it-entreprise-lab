# Microsoft Intune Overview

## Objective

The objective of this section is to review the Microsoft Intune administration environment and identify the main components used for modern endpoint management.

---

## Context

Microsoft Intune is Microsoft's cloud-based endpoint management solution. It provides centralized management of organizational devices, applications, configuration policies, compliance requirements, and endpoint security.

Intune integrates with Microsoft Entra ID to provide identity-based device management and policy assignment.

This section focuses on reviewing the Intune administration environment before performing any configuration changes.

---

## Intune Admin Center

The Microsoft Intune admin center provides the centralized administrative interface for managing organizational endpoints.

The main management areas reviewed during this laboratory include:

* Devices
* Apps
* Endpoint security
* Tenant administration
* Reports
* Policy and configuration management

The Devices section provides centralized visibility into devices managed through Microsoft Intune.
