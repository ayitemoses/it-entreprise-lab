# Verify Microsoft 365 Services

## Objective

Verify that Microsoft 365 services are available and accessible after tenant configuration, user creation, and license assignment.

## Steps

1. Sign in to the Microsoft 365 portal.
2. Open the Microsoft 365 app launcher.
3. Verify access to the available Microsoft 365 services.
4. Test the following applications:

   * Outlook
   * Microsoft Teams
   * OneDrive
   * SharePoint
5. Review the Microsoft 365 Admin Center for any service alerts or licensing issues.

## Verification

* Microsoft 365 services are available.
* Licensed users can access the assigned services.
* No critical service or licensing issues are reported.

## Result

The Microsoft 365 environment has been successfully verified. Users, licenses, groups, and cloud services are operational and ready for integration with Microsoft Entra ID and Microsoft Intune in the next laboratory.
