# LAB 09 - Microsoft Intune

## Context

This laboratory consists of deploying and configuring Microsoft Intune as the modern endpoint management solution for the Enterprise IT Lab.

Microsoft Intune will be used to manage organizational devices, configure security and compliance policies, deploy applications, and integrate endpoint management with Microsoft Entra ID.

---

# Objectives

* Access the Microsoft Intune admin center
* Review the Microsoft Intune environment
* Configure Microsoft Intune device management
* Review Microsoft Entra ID integration
* Configure device enrollment settings
* Create and assign device configuration policies
* Configure compliance policies
* Deploy and manage applications
* Review endpoint security capabilities
* Validate device management functionality
* Document licensing limitations and available features
