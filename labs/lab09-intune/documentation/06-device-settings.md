# Configure Intune Device Settings

## Objective

Create a device configuration profile in Microsoft Intune and assign it to the managed Windows device.

## Steps

1. Sign in to the Microsoft Intune admin center.
2. Navigate to **Devices → Configuration**.
3. Select **Create** and create a new configuration profile.
4. Select **Windows 10 and later** as the platform.
5. Select **Settings catalog** as the profile type.
6. Enter a descriptive name for the configuration profile.
7. Add the required device settings.
8. Review the configuration settings.
9. Assign the profile to the appropriate device or user group.
10. Create the configuration profile.
11. Open the profile and review its configuration and assignment status.
12. Verify the policy status on the managed Windows device.


## Verification

* Successfully accessed Intune configuration profiles.
* Created a Windows device configuration profile.
* Configured the required device settings.
* Assigned the profile to the appropriate target.
* Verified the configuration profile status.
* Confirmed the policy was successfully applied to the managed device.

## Result

A Windows device configuration profile was successfully created and assigned through Microsoft Intune.

The managed Windows device can now receive centralized configuration settings through Intune.
