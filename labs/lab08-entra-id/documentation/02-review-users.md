# Review Microsoft Entra Users

## Objective

Verify that Microsoft 365 cloud users are available in Microsoft Entra ID.

## Steps

1. Open the Microsoft Entra admin center.
2. Navigate to:

   * Identity
   * Users
   * All users
3. Verify that previously created Microsoft 365 users are displayed.
4. Review user properties:

   * Display name
   * User Principal Name (UPN)
   * User type
   * Account status

## Verification

* Microsoft 365 users are visible in Microsoft Entra ID.
* User accounts are enabled.
* User information is correctly synchronized within the cloud tenant.

## Result

Cloud users created in Microsoft 365 are available in Microsoft Entra ID and ready for identity management tasks.
