# Link Group Policy Object

## Objective

Link the **IT Desktop Policy** Group Policy Object to the **IT** Organizational Unit.

## Steps

1. Open Group Policy Management.
2. Navigate to the **IT** Organizational Unit.
3. Select **Link an Existing GPO**.
4. Choose **IT Desktop Policy**.

## Result

The Group Policy Object is now linked to the IT Organizational Unit and will apply to users and computers located in that OU.
