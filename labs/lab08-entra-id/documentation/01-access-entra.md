# Access Microsoft Entra Admin Center

## Objective

Access the Microsoft Entra admin center and verify the tenant configuration.

## Steps

1. Sign in to the Microsoft Entra admin center.
2. Verify the correct Microsoft 365 tenant is selected.
3. Confirm the Global Administrator account is being used.
4. Review the main navigation sections:

   * Identity
   * Users
   * Groups
   * Roles and administrators
   * Protection
   * Devices

## Verification

* Successfully accessed the Microsoft Entra admin center.
* Verified the correct tenant.
* Confirmed Global Administrator privileges.

## Result

The Microsoft Entra environment is accessible and ready for identity and access management tasks.
