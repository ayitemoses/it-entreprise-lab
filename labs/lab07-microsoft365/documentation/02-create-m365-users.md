# Create Microsoft 365 Users

## Objective

Create cloud-only users in the Microsoft 365 tenant to prepare for identity management, licensing, and future Microsoft Entra ID and Intune labs.

## Steps

1. Sign in to the Microsoft 365 Admin Center.
2. Navigate to **Users > Active users**.
3. Select **Add a user**.
4. Create the following cloud users:

   * John Smith
   * Jane Doe
   * Bob Wilson
   * Alice Brown
5. Configure each user's:

   * Display name
   * Username
   * Department
   * Job title
6. Generate a temporary password.
7. Enable the option to require a password change at first sign-in.
8. Save each user account.

## Verification

* All users appear in the **Active users** list.
* Each account is enabled.
* User information is correctly configured.
* Temporary passwords have been generated.

## Result

Four cloud-only users were successfully created and are ready for Microsoft 365 license assignment and future cloud management tasks.
