# Assign Microsoft 365 Licenses

## Objective

Assign Microsoft 365 licenses to cloud users.

## Steps

1. Open Microsoft 365 Admin Center.
2. Navigate to Users > Active users.
3. Select each user.
4. Open Licenses and apps.
5. Assign an available Microsoft 365 license.
6. Save the changes.

## Verification

- Licenses successfully assigned.
- Microsoft 365 services are enabled.
- Users are ready to access cloud services.

## Result

All cloud users have valid Microsoft 365 licenses and can use the assigned services.
